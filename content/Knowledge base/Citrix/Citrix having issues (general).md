One way that can help is to reset the workspace.

**NOTE: If user is working in the web browser version, ensure all work is saved as it will kick them out!**

Reset the workspace:

- In the service tray right click citrix.
![[Pasted image 20241231123609.png]]

- Go to advanced preferences

- Hit Reset Citrix Workspace
