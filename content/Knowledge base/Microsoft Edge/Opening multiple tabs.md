With **Edge**, we can no longer set preset tabs to open when opening the browser.

As inconvenient as this may be, there is a fix that will only require you to click one button.

With **Edge** open, create a new folder within favourites:

- In **Edge**, click the **favourites button** and click the symbol to **create a new folder** 

- Name the folder whatever you wish. For this example, I've called the folder "Open on startup"

![[Pasted image 20241231124614.png]]

- If you don't have any pages (or the pages you wish to be opened on startup) saved in your favourites, go ahead and add them to your newly created folder.

- If the pages are already in your favourites, you can drag and drop them into the newly created folder.
![[Pasted image 20241231124636.png]]

- With the pages you wish to be opened all in one folder and in the favourites bar, upon opening edge, use the **middle mouse button** (the scroll wheel) to click on the folder. This will open all the pages into new tabs.
![[Pasted image 20241231124702.png]]

- Granted, the tabs don't open when opening the web browser, however it does only mean you have to click once.
