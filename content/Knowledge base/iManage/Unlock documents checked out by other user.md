This is when someone leaves a document open but may be out the office. Advise we can unlock it but if the other user has been making changes they will be lost!

Reason for this is how the Recent folder works.  When a document has been checked-out, this folder holds a local copy of that file while the user is working on it. The auto save will save back to this and ONLY when this document has been checked back in to Imanage, will these changes copy back to Imanage.

Before doing this, please check with the user if they have any changes that need to be saved beforehand or else it will be lost after completing these steps. 

I**f the user has changes to be saved, please Remote On and browse to the user’s Recent folder within their H drive and rename the local saved version first.** 

This way, the local copy keeps the unsaved data which will then allow the user to copy the data across.

- To unlock a document, you will need the Doc ID from user. Once you have this go to iManage Control Centre (IMCC)   [https://dms/work/cc](https://dms/work/cc "https://dms/work/cc"). You may need to use your xfb admin account for this.
- Select Documents down the left-hand side. Note there is also Workspaces if needing to search for workspace access.
- You can search by doc ID or the user who has the document checked out.

![[Pasted image 20241231131108.png]]

- Once you have found the document check the Doc ID. In above example it is **22494061**. Select the document and you will get several options or along the top. The same options are available clicking the three dots to the far right of the document.
- Choose Unlock. You will have to put in a reason (use the ticket number). Enter the request ID and the name of the person who has requested the unlock. Click Unlock.
