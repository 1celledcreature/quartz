When a user has forgotten the pin for their work phone and can't unlock it.

- Go to Entra admin center (AAD)
- Fin the user who's phone needs to be unlocked
- Click devices in the user pane

![[Pasted image 20241231130006.png]]

- Select the work iPhone that shows in the list
- Select 'Manage'
![[Pasted image 20241231130040.png]]

In the top pane, select the 'Remove Passcode'
![[Pasted image 20241231130103.png]]

Be sure to advise the user to set a new pin.
