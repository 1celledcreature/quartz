**Pdfinfo**  
Install: sudo apt install poppler-utils  

Description: Displays metatdata related to PDF file  

Example: pdfinfo DOCUMENT.pdf
 

**Exiftool**  
Install: sudo apt install libimage-exiftool-perl  

Description: Can extract metatdata from jpg's like GPS co-ordinates of where the pic was taken  

Example: exiftool IMAGE.jpg


**Spiderfoot**
Install: sudo apt install spiderfoot

Description: Displays metatdata related to PDF file  

Example: pdfinfo DOCUMENT.pdf
