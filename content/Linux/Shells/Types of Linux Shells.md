**Bourne Again Shell (BASH)**
	Default shell for most linux distros
	Is the latest type of Shell and has unique abilities.
	Key features include:
		*Tab completion feature* - If in the middle of completing a command, hitting tab will auto complete based on possible match or give suggestions to complete it.
		*Keeps history* - Keeps logs on all commands executed. Can use up or down arrows to scroll through most recent commands. Can also type *history* to display all previous commands.

**Friendly Interactive Shell (FISH)**
	Not default in most distro's.
	Focuses on user friendly-ness than other shells.
	Ket features include:
		*syntax* - very simple, feasible for beginners
		*Auto spell* - unlike bash
		*Customise* - can customise the CMD with themes
		*Colours* - colours commands based on their roles. can help spot errors.
		*BASH* - offers all functions that BASH does.

**Z Shell (zsh)**
	Installed by default
	combines functionalities of the previous 2.
	Key features:
		*Scripts* - Advanced tab completion and is capable of writing scripts.
		*auto spell* - like FISH
		*customisation* - but makes it slower than other shells.
