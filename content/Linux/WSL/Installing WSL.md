Windows sub-system for linux
Virtualisation may need to be enabled on the machine, this can be done in the BIOS settings upon boot.

In windows 11 power shell, use the command: *wsl --install*

UAC will prompt a few times for acceptance. 

Once installation is complete. The machine will need a restart.

Once the restart has finished, a username and password will be prompted to be created.

![[Pasted image 20250119155628.png]]

To exit: *exit

To enter (via powershell terminal): *wsl -d ubuntu
