Windows commands can be ran in the linux terminal by adding *.exe*
	eg *ipconfig.exe*
	or *ping.exe*

open files
	eg *notepad.exe filename.txt*

Machine list (whats running): *wsl --list --verbose*

Turn off all machines: *wsl --shutdown*

Turn off one machine: *wsl --terminate (distro)*

uninstall: *wsl --unregister (distro)*

Kali desktop install - instant kali desktop in windows:
	*sudo apt install kali-win-kex -y*
	will ask to create password
	Kali desktop will launch
