You can administer/assign different ports to that interact with applications.

- E.g http on 8080 opposed to 80.

Applications will assume a standard is being followed, so a colon : will have to be provided along with the port number.

*port 7* - echo server. Echos everything thats sent to it
*port 13* - Daytime server. replies with current dat and time
*port 21* - FTP
*port 22* - SSH
*port 23* - telnet
*Port 25* - SMTP
*port 53* - DNS (UDP)
*Ports 80* - HTTP
*port 110* - POP3
*port 143* - IMAP
*port 443* - HTTPS
*port 465 + 587* - SMTPS
*port 995* - POP3s
*port 993* - IMAPS
