- A term given to splitting up a network into smaller networks/versions of itself.
- Subnetting decided who gets what on the network.
- Network admins to assign different parts of the network.

- Subnetting is done by splitting up the number of hosts that can fit in a network, represented by a number (subnet)
- Subnets also use the range 0-255
- Subnets use IP in 3 different ways
    
    - Identify the network address
    - Identify the host
    - Identify default gateway
- Subnetting benefits
    
    - Efficiency
    - Security
    - Full control
