Security controls
 
- Technical controls
    
    - By using systems, implementing policies ect
    - Firewalls and anti-virus
- Managerial Controls
    
    - Policies that explain to people the best way to manage their devices and data ect
    - When creating a security policy documentation, you'd put these inside the policies
    - Integrated into standard day-to-day operating procedures
- Operational Controls
    
    - Operated by people opposed to software/systems
    - Security guards and awareness programs and an example
- Physical controls
    
    - Limit physical access
    - Locks, fences, guard shacks, badge readers ect
 
Control types

- Preventive
- Deterrent
- Detective
- Corrective
- Compensating
- Directive

Will all vary from company to company.
