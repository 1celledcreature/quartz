**Security Operations Centre**
 
Team of security pros that monitor the network and its systems to detect malicious cyber security events.
 
Main areas of interest:

- Vulnerabilities - When a system weakness is discovered it must be fixed with update or patch. If this is not available, measures must be taken to prevent an attacker exploiting it. This is not necessarily assigned to SOC.

- Policy violations - A set of rules required for the protection of the network and systems. E.G users uploading company data to an online storage device.

- Unauthorised activity - SOC needs to detect when a users login details are stolen ASAP before significant damage is done.

- Network intrusions - Can occur when user clicks on malicious link of an attacker exploiting a public server. Must be detected early as possible.
