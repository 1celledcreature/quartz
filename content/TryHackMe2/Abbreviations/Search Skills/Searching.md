**Evaluation of search results**:
Source - Identify the author. Reputable?
Evidence + Reasoning - are claims backed by evidence?
Objectivity and bias - Is the info impartial?
Corroboration and consistency - validate info from multiple independent sources.

Term: *Snake Oil* - Cryptographic method or product considered bogus or fraudulent

**Using Search Engines**
*"exact phrase"* - Double quotes get pages with exact phrase

*site:* - specify the domain of the site to search. e.g. 'site:tryhackme.com success stories'

*-:* omit search word or phrase. e.g. 'pyramids -tourism'

*filetype:* Find files instead of web pages. PDF, DOC, XLS, PPT. e.g. 'filetype:ppt cyber security'


**Specialised Search Engines**
*Shodan* - https://www.shodan.io/
Search engine for devices connected to the internet.
Servers, Network equipment, industrial control systems and IoT devices.
E.g. when we search 'Apache 2.4.1', we can see how many servers are running that with it in their headers.

*Censys* - https://docs.censys.com/docs/ls-introductory-use-cases#/
Focuses on internet-connected hosts, websites, certificates and other internet assets.

*VirusTotal* - https://www.virustotal.com/gui/home/upload
Provides virus scanning service for files using multi antivirus engines.
Can upload files/URL's to can multiple places in one go.
Can input file hashes to check for previously uploaded files.
Might not always be 100% accurate but has community input

*Have i Been Pwned* - https://haveibeenpwned.com/
Tells you if an email address has been involved in a data breach
Passwords could be used across accounts if one email password was breached.
