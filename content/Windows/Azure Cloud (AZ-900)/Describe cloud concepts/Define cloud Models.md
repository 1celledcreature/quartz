Private Cloud
	Used by a single entity (one organisation)
	can be hosted on-site, a dedicated datacenter or 3rd party

Public cloud
	Built, controlled and maintained by a 3rd party
	anyone that wants to purchase the resources can purchase

Hybrid Cloud
	Uses a mix of the two above interconnected
	allows a private cloud to temporarily increase resources
	can be used for extra security
	users can choose to keep public or their own private infrastructure

|**Public cloud**|**Private cloud**|**Hybrid cloud**|
|---|---|---|
|No capital expenditures to scale up|You have complete control over resources and security|Provides the most flexibility|
|Applications can be quickly provisioned and deprovisioned|Data isn't collocated with other tenants' data|You determine where to run your applications|
|You pay only for what you use|Hardware must be purchased for startup and maintenance|You control security, compliance, or legal requirements|
|You don't have complete control over resources and security|You are responsible for hardware maintenance and updates||M
Multicloud
	Uses multiple public clouds
	Useful for using different features from different providers
	always dealing with 2 or more different cloud providers

Azure Arc
	Tech that helps mange cloud environment
	Regardless of cloud infrastructure type (private, hybrid, multicloud ect)

Azure VMware Solution
	Assists in migrating established cloud environments
		e.g private to public
