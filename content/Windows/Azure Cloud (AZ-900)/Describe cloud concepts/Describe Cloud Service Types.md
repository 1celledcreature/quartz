**IaaS** - Infrastructure as a service
	Cloud provider is responsible for maintaining hardware, network connectivity and physical security.
	Business is responsible for everything else:
		OS installs, config and maintenance
		Network configuration
		Database and storage configuration
	You're essentially renting the Hardware, what you do is up to you.
	![[Pasted image 20260413153034.png|520]]
	Responsibility
		You manage the workload. OS, patching, config and most of security.
		![[Pasted image 20260413153357.png|512]]
	Common scenarios include:
		'Lift and shift' - Setting up cloud resources similar to on-prem, then move across.
		'Testing and Development' - Being able to start up and shut down environments quickly and easily.

**PaaS** - Platform as a service
	Middle ground between IaaS and SaaS.
	Cloud provider manages:
		Physical infrastructure
		Physical Security
		Internet connection
		OS's
		Middleware
		Dev tools
		Analytics.
	No need to worry about licensing or patching.
	Suited to providing Development environments.
	![[Pasted image 20260413154440.png]]
	Scenarios:
		Dev framework - devs can build, develop and customise cloud apps.
		Analytics or business intelligence - Allow teams to analyse and mine their data for insights and predict outcomes for planning and operational decisions.

**SaaS** - Software as a service
	Renting/using FULLY developed applications.
	Examples:
		email
		finance software
		messaging apps
		connectivity software
	Is the least flexible, but easy to get going (very limited tech experience needed)
	Provider manages everything
		applications + maintenance 
		Infrastructure
		platform
	You look after data, identity and access settings.
	Has the lowest operational overhead.
