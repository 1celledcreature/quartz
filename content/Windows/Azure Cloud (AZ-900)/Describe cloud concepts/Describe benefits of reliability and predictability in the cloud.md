Reliability
	Able to recover from system failures
	cloud is de-centralised, supporting reliability and resilience
	cloud environment will auto shift to the closest region to you.

Predicability
	![[Pasted image 20260427170526.png]]
	can be focused on performance or cost
	Performance
		focuses on predicting resources needed.
		autoscaling, load balancing and high availability are a few of the cloud concepts that support predicability.
		autoscaling deploys additional resources to meet demand and scale back when demand drops.
		Heavy traffic will load balance to help stressed areas.
	Cost
		Forecasts cloud spending.
		by analysing recent use, can use predictability to foresee future costs by applying data analytics.
