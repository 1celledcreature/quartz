
High Availability
	Regardless of disruptions, resources are available.
	Formal Guarantee's have to be put in place as part of the SLA's (service level agreement)
		represented as a percentage (uptime and downtime)
		100% is expensive due to having to replicate everything before maintenance can be done.
		99/99.9/99.95% are more common SLA's
		99% availability can be down 1.68 hours per week for example. 99.9% is only 10 mins a week.
	Each application has it's own SLA.

Scalability
	Ability to meet resources to meet demand.
	When resources are low, easy to scale and create more.
	You don't overpay for services (pay for what you use), consumption-based model.
	Scaling comes in vertical and horizontal
		Vertical 
			Increase/decrease the capabilities of resources
			Developing an app: if you need more CPU or RAM.
		Horizontal 
			adding more resources.
			add additional VM's or containers
			Can be done automatically or manually
