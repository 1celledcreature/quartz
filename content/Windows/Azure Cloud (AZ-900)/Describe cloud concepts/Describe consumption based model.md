Instead of buying and maintaining hardware, you rent the compute power, storage and give back when you're done.

CapEx (capital expenditure)
	refers to upfront spending on physical infrastructure
		servers, network hardware, datacenter space

OpEx (operational expenditure)
	refers to ongoing expenditure
	cloud services are paid for as you use them, therefore cloud computing is OpEx

Key benefits of consumption based model
	No upfront costs of hardware or infrastructure
	Don't need to purchase or manage things that aren't used
	Add and remove resources on demand

Capacity planning: Traditional vs cloud

Traditional
	Estimate future costs
	can overestimate or overspend on infrastructure
	If underestimated, apps can underperform
	fixing the issues mean ordering and installing more hardware ect

Cloud
	Adjust resources to match demand
	Add VM's at will to increase capacity, then can be removed if needed
	scale up or down depending on the traffic of data/demand

Cloud pricing
	Essentially pay-as-you-go, which helps to
		Plan and manage costs
		run infra more efficiently
		scale workload as needed

 Cloud provider maintains and manages all hardware. Allowing the business to focus on whats important.
